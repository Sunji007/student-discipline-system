# Data Dictionary - ระบบบริหารงานวินัยและพฤติกรรมนักเรียน

เอกสารพจนานุกรมข้อมูล (Data Dictionary) สำหรับโครงสร้างระบบฐานข้อมูลทั้งหมดของระบบบริหารงานวินัยและติดตามพฤติกรรมนักเรียน โรงเรียนศิริราษฎร์สามัคคี

---

## 1. หมวดหมู่ผู้ใช้งานและข้อมูลบุคคล (User & Profile Tables)

### 1.1 ตาราง `users` (ตารางข้อมูลผู้ใช้งานหลัก)
เก็บข้อมูลสำหรับการลงชื่อเข้าสู่ระบบ บัญชีผู้ใช้งาน และข้อมูลการติดต่อเบื้องต้นของทุกบทบาทในระบบ
| ชื่อคอลัมน์ (Column Name) | ประเภทข้อมูล (Data Type) | คีย์ (Key) | ค่าเริ่มต้น (Default) | คำอธิบาย (Description) |
| :--- | :--- | :--- | :--- | :--- |
| **UserID** | VARCHAR(36) | Primary Key | - | รหัสผู้ใช้ประจำตัวในรูปแบบ UUID |
| **Username** | VARCHAR(50) | Unique | - | รหัสประจำตัวสำหรับเข้าใช้งานระบบ (เช่น รหัสนักเรียน/รหัสครู) |
| **Password** | VARCHAR(60) | - | - | รหัสผ่านผู้ใช้งานที่ผ่านการเข้ารหัสแล้ว (Bcrypt/Hashed) |
| **CitizenID** | VARCHAR(13) | Unique / Nullable | Null | รหัสประจำตัวประชาชน 13 หลัก ของผู้ใช้งาน |
| **FirstName** | VARCHAR(50) | - | - | ชื่อจริง (ภาษาไทย) |
| **LastName** | VARCHAR(50) | - | - | นามสกุล (ภาษาไทย) |
| **FirstName_EN** | VARCHAR(50) | Nullable | Null | ชื่อจริง (ภาษาอังกฤษ) |
| **LastName_EN** | VARCHAR(50) | Nullable | Null | นามสกุล (ภาษาอังกฤษ) |
| **Role** | VARCHAR(50) | - | - | บทบาทผู้ใช้งานในระบบ (`ผู้ดูแลระบบ`, `ฝ่ายปกครอง`, `ครู`, `นักเรียน`, `ผู้ปกครอง`) |
| **Email** | VARCHAR(100) | Unique / Nullable | Null | อีเมลส่วนบุคคล (ใช้ส่งลิงก์เพื่อขอตั้งรหัสผ่านใหม่) |มี
| **Phone** | VARCHAR(10) | Nullable | Null | เบอร์โทรศัพท์สำหรับติดต่อ |
| **Status** | VARCHAR(50) | - | `'ปกติ'` | สถานะการเปิดใช้งานบัญชี (`ปกติ`, `ระงับการใช้งาน`) |
| **AdditionalInfo** | VARCHAR(255) | Nullable | Null | ข้อมูลบันทึกประวัติเพิ่มเติม |
| **remember_token** | VARCHAR(100) | Nullable | Null | โทเค็นจดจำการล็อกอินอัตโนมัติ (Remember Me) |
| **created_at** | Timestamp | - | Current | วันเวลาที่ลงทะเบียนผู้ใช้นี้ |
| **updated_at** | Timestamp | - | Current | วันเวลาที่มีการแก้ไขข้อมูลล่าสุด |

### 1.2 ตาราง `students` (ตารางข้อมูลนักเรียน)
เก็บรายละเอียดของนักเรียน เชื่อมโยงกับผู้ใช้งานหลักและประวัติคะแนนความประพฤติ
| ชื่อคอลัมน์ | ประเภทข้อมูล | คีย์ | ค่าเริ่มต้น | คำอธิบาย |
| :--- | :--- | :--- | :--- | :--- |
| **StudentID** | VARCHAR(10) | Primary Key | - | รหัสประจำตัวนักเรียน (เช่น 10007) |
| **UserID** | VARCHAR(36) | Foreign Key | - | อ้างอิงตาราง `users.UserID` (Cascade Delete) |
| **ParentID** | VARCHAR(36) | Foreign Key | Null | อ้างอิงตาราง `parents.ParentID` (Set Null) |
| **FirstName** | VARCHAR(50) | - | - | ชื่อจริงนักเรียน (ภาษาไทย) |
| **LastName** | VARCHAR(50) | - | - | นามสกุลนักเรียน (ภาษาไทย) |
| **FirstName_EN** | VARCHAR(50) | Nullable | Null | ชื่อจริงนักเรียน (ภาษาอังกฤษ) |
| **LastName_EN** | VARCHAR(50) | Nullable | Null | นามสกุลนักเรียน (ภาษาอังกฤษ) |
| **Gender** | VARCHAR(10) | Nullable | Null | เพศวิถีนักเรียน (`ชาย`, `หญิง`) |
| **Photo** | VARCHAR(255) | Nullable | Null | พาธไฟล์รูปถ่ายหน้าตรงของนักเรียน |
| **GradeLevel** | VARCHAR(10) | Nullable | Null | ระดับชั้นปีการศึกษา (เช่น ม.1, ม.6) |
| **Classroom** | VARCHAR(10) | Nullable | Null | ห้องเรียนของนักเรียน (เช่น 1, 2) |
| **BehaviorScore** | Integer | - | `100` | คะแนนความประพฤติสะสมของนักเรียน ณ ปัจจุบัน |
| **RiskStatus** | VARCHAR(50) | - | `'ปกติ'` | การแบ่งกลุ่มพฤติกรรมเสี่ยง (`ปกติ`, `กลุ่มเสี่ยง`) |

### 1.3 ตาราง `parents` (ตารางข้อมูลผู้ปกครอง)
เก็บรายละเอียดข้อมูลผู้ปกครองเพื่อทำการผูกสิทธิ์เข้าดูแลนักเรียน
| ชื่อคอลัมน์ | ประเภทข้อมูล | คีย์ | ค่าเริ่มต้น | คำอธิบาย |
| :--- | :--- | :--- | :--- | :--- |
| **ParentID** | VARCHAR(36) | Primary Key | - | รหัสผู้ปกครองรูปแบบ UUID |
| **UserID** | VARCHAR(36) | Foreign Key | - | อ้างอิงตาราง `users.UserID` (Cascade Delete) |
| **StudentID** | VARCHAR(10) | Foreign Key | Null | รหัสนักเรียนภายใต้การปกครองหลัก |
| **Relationship** | TINYINT | - | - | ความสัมพันธ์ร่วมกับนักเรียน (`1` = พ่อ, `2` = แม่, `3` = ญาติ) |
| **FirstName** | VARCHAR(50) | - | - | ชื่อจริงผู้ปกครอง (ภาษาไทย) |
| **LastName** | VARCHAR(50) | - | - | นามสกุลผู้ปกครอง (ภาษาไทย) |
| **FirstName_EN** | VARCHAR(50) | Nullable | Null | ชื่อจริงผู้ปกครอง (ภาษาอังกฤษ) |
| **LastName_EN** | VARCHAR(50) | Nullable | Null | นามสกุลผู้ปกครอง (ภาษาอังกฤษ) |
| **CitizenID** | VARCHAR(13) | Unique / Nullable | Null | รหัสประจำตัวประชาชนของผู้ปกครอง |
| **Phone** | VARCHAR(10) | Nullable | Null | เบอร์โทรศัพท์สำหรับการโทรติดต่อ |
| **Email** | VARCHAR(100) | Nullable | Null | อีเมลสำหรับติดต่อ |
| **Address** | Text | Nullable | Null | ที่อยู่อาศัยปัจจุบัน |

### 1.4 ตาราง `teachers` (ตารางข้อมูลครู)
เก็บข้อมูลฝ่ายวิชาการและสังกัดกลุ่มสาระวิชาการเรียนรู้ของครูแต่ละคน
| ชื่อคอลัมน์ | ประเภทข้อมูล | คีย์ | ค่าเริ่มต้น | คำอธิบาย |
| :--- | :--- | :--- | :--- | :--- |
| **TeacherID** | VARCHAR(36) | Primary Key | - | รหัสประจำตัวครู (เช่น 20001) |
| **UserID** | VARCHAR(36) | Foreign Key | - | อ้างอิงตาราง `users.UserID` (Cascade Delete) |
| **Department** | VARCHAR(100) | Nullable | Null | กลุ่มสาระวิชาการเรียนรู้ที่ครูสังกัด |

### 1.5 ตาราง `teacher_advisory_rooms` (ตารางห้องที่ปรึกษาครู)
เก็บข้อมูลห้องเรียนที่ครูแต่ละคนเป็นครูที่ปรึกษา (รองรับครูประจำชั้นเป็นที่ปรึกษาได้ไม่จำกัดจำนวนห้อง)
| ชื่อคอลัมน์ | ประเภทข้อมูล | คีย์ | ค่าเริ่มต้น | คำอธิบาย |
| :--- | :--- | :--- | :--- | :--- |
| **teacher_advisory_room_id** | BigInteger | Primary Key | Auto Inc | รหัสรายการลำดับในฐานข้อมูล |
| **TeacherID** | VARCHAR(36) | Foreign Key | - | รหัสประจำตัวครู อ้างอิงตาราง `teachers.TeacherID` (Cascade Delete) |
| **Classroom** | VARCHAR(10) | - | - | ห้องเรียนที่ครูดูแลที่ปรึกษา (เช่น 1/1, 2/2, 6/3) |

### 1.6 ตาราง `discipline_staff` (ตารางบุคลากรฝ่ายปกครอง)
เก็บสิทธิ์ระดับการเข้าบันทึกหรืออนุมัติความประพฤติระดับปกครอง
| ชื่อคอลัมน์ | ประเภทข้อมูล | คีย์ | ค่าเริ่มต้น | คำอธิบาย |
| :--- | :--- | :--- | :--- | :--- |
| **StaffID** | VARCHAR(36) | Primary Key | - | รหัสเจ้าหน้าที่ฝ่ายปกครอง |
| **UserID** | VARCHAR(36) | Foreign Key | - | อ้างอิงตาราง `users.UserID` (Cascade Delete) |
| **Position** | VARCHAR(100) | Nullable | Null | ตำแหน่งบริหารฝ่ายงานวินัย |
| **Level** | TINYINT | - | `1` | สิทธิ์การเข้าใช้งานระบบ (`1` = บันทึกได้, `2` = อนุมัติผล/ตั้งค่า) |

## 2. หมวดหมู่พฤติกรรมและคำร้องวินัย (Behavior & Discipline Tables)

### 2.1 ตาราง `behavior_rules` (ตารางกฎเกณฑ์พฤติกรรม)
เก็บเกณฑ์การหักคะแนนและบวกคะแนนความประพฤติตามกฎระเบียบสถานศึกษา
| ชื่อคอลัมน์ | ประเภทข้อมูล | คีย์ | ค่าเริ่มต้น | คำอธิบาย |
| :--- | :--- | :--- | :--- | :--- |
| **RuleID** | VARCHAR(36) | Primary Key | - | รหัสข้อกฎข้อบังคับวินัย |
| **RuleName** | VARCHAR(100) | - | - | ชื่อพฤติกรรมวินัยการกระทำความผิด/ความดี |
| **RuleType** | VARCHAR(50) | - | - | ประเภทการปรับปรุงคะแนน (`ตัดคะแนน`, `เพิ่มคะแนน`) |
| **ScoreModifier** | Integer | - | - | จำนวนคะแนนที่จะถูกปรับเปลี่ยน (ติดลบหรือเป็นบวก) |
| **Category** | VARCHAR(100) | Nullable | Null | หมวดหมู่กฎพฤติกรรม |
| **Description** | Text | Nullable | Null | รายละเอียดอธิบายกฎระเบียบเพิ่มเติม |

### 2.2 ตาราง `behavior_records` (ตารางบันทึกพฤติกรรม)
เก็บรายการบันทึกพฤติกรรมความดีหรือความผิดของนักเรียน
| ชื่อคอลัมน์ | ประเภทข้อมูล | คีย์ | ค่าเริ่มต้น | คำอธิบาย |
| :--- | :--- | :--- | :--- | :--- |
| **RecordID** | VARCHAR(36) | Primary Key | - | รหัสบันทึกประวัติความประพฤติรายครั้ง |
| **StudentID** | VARCHAR(10) | Foreign Key | - | อ้างอิงตาราง `students.StudentID` |
| **RuleID** | VARCHAR(36) | Foreign Key | - | อ้างอิงตาราง `behavior_rules.RuleID` |
| **semester_id** | BigInteger | Foreign Key | Null | ภาคเรียนที่บันทึก อ้างอิงตาราง `semesters.semester_id` (Set Null) |
| **RecordDate** | Date | - | - | วันเวลาที่นักเรียนกระทำพฤติกรรมดังกล่าว |
| **Description** | Text | Nullable | Null | บันทึกรายละเอียดข้อมูลรายละเอียดเหตุการณ์จริง |
| **RecordedBy** | VARCHAR(36) | Foreign Key | - | ผู้บันทึกประวัติ อ้างอิงตาราง `users.UserID` |
| **Status** | VARCHAR(50) | - | `'รออนุมัติ'` | สถานะใบรายการพฤติกรรม (`รออนุมัติ`, `อนุมัติแล้ว`, `ยกเลิก`) |
| **Penalty** | VARCHAR(100) | Nullable | Null | รายละเอียดการสั่งลงโทษทัณฑ์เพิ่มเติม |

### 2.3 ตาราง `appeals` (ตารางคำร้องโต้แย้งคะแนนความประพฤติ)
เก็บการยื่นคำชี้แจงเพื่อปฏิเสธการตัดคะแนนจากนักเรียน
| ชื่อคอลัมน์ | ประเภทข้อมูล | คีย์ | ค่าเริ่มต้น | คำอธิบาย |
| :--- | :--- | :--- | :--- | :--- |
| **AppealID** | VARCHAR(36) | Primary Key | - | รหัสอ้างอิงใบคำร้องโต้แย้ง |
| **RecordID** | VARCHAR(36) | Foreign Key | - | อ้างอิงตาราง `behavior_records.RecordID` |
| **StudentID** | VARCHAR(10) | Foreign Key | - | นักเรียนผู้เขียน อ้างอิงตาราง `students.StudentID` |
| **Reason** | Text | - | - | เหตุผลข้อชี้แจงเพิ่มเติมในการยื่นคำร้องโต้แย้ง |
| **EvidencePath** | VARCHAR(255) | Nullable | Null | พาธไฟล์รูปถ่ายเอกสารหรือหลักฐานที่อัปโหลด |
| **AppealDate** | Date | - | - | วันที่กดยื่นเรื่องโต้แย้งคะแนน |
| **Status** | VARCHAR(50) | - | `'รอตรวจสอบ'` | สถานะตรวจสอบเรื่อง (`รอตรวจสอบ`, `คืนคะแนน`, `ยกเลิกคำร้อง`) |
| **ReviewerID** | VARCHAR(36) | Foreign Key | Null | ผู้ตรวจทานใบโต้แย้ง อ้างอิงตาราง `users.UserID` |
| **ReviewDate** | Date | Nullable | Null | วันที่ดำเนินการตรวจพิจารณาเสร็จสิ้น |
| **ReviewNotes** | Text | Nullable | Null | ความคิดเห็นประกอบการตัดสินใจพิจารณา |

## 3. หมวดหมู่กิจกรรมและการเรียนศาสนา (Attendance & Religious Practice Tables)

### 3.1 ตาราง `attendances` (ตารางบันทึกการเข้าแถวหน้าเสาธง)
| ชื่อคอลัมน์ | ประเภทข้อมูล | คีย์ | ค่าเริ่มต้น | คำอธิบาย |
| :--- | :--- | :--- | :--- | :--- |
| **AttendanceID** | VARCHAR(36) | Primary Key | - | รหัสใบเช็ครายชื่อเข้าแถว |
| **StudentID** | VARCHAR(10) | Foreign Key | - | อ้างอิงตาราง `students.StudentID` |
| **semester_id** | BigInteger | Foreign Key | Null | ภาคเรียนที่บันทึก อ้างอิงตาราง `semesters.semester_id` (Set Null) |
| **Date** | Date | - | - | วันที่เข้ากิจกรรมหน้าเสาธง |
| **Status** | VARCHAR(50) | - | - | ผลการเช็คชื่อเข้าแถว (`มา`, `สาย`, `ขาด`, `ลา`) |
| **RecordedBy** | VARCHAR(36) | Foreign Key | - | อ้างอิงตาราง `users.UserID` ของครูเวร/ผู้บันทึก |

### 3.2 ตาราง `prayer_records` (ตารางบันทึกเช็คชื่อละหมาดรายวัน)
เก็บข้อมูลเช็คชื่อปฏิบัติศาสนกิจ (ละหมาดซุฮ์รีและอัศรี)
| ชื่อคอลัมน์ | ประเภทข้อมูล | คีย์ | ค่าเริ่มต้น | คำอธิบาย |
| :--- | :--- | :--- | :--- | :--- |
| **PrayerRecordID** | VARCHAR(36) | Primary Key | - | รหัสการบันทึกการเช็คละหมาด |
| **StudentID** | VARCHAR(10) | Foreign Key | - | อ้างอิงตาราง `students.StudentID` |
| **semester_id** | BigInteger | Foreign Key | Null | ภาคเรียนที่บันทึก อ้างอิงตาราง `semesters.semester_id` (Set Null) |
| **RecordDate** | Date | - | - | วันที่ดำเนินกิจกรรม |
| **RecordTime** | Time | - | - | เวลาที่นักเรียนมาเช็คชื่อ |
| **Period** | VARCHAR(20) | - | - | ช่วงเวลาละหมาด (`เที่ยง`, `บ่าย`) |
| **Status** | VARCHAR(50) | - | - | สถานะการละหมาด (`ละหมาด`, `ละหมาดไม่ได้` *เช่น กรณีนักเรียนหญิงมีรอบเดือน*) |
| **RecordedBy** | VARCHAR(36) | Foreign Key | - | อ้างอิงตาราง `users.UserID` ของครูหรือนักเรียนเวร |

### 3.3 ตาราง `prayer_corrections` (ตารางบันทึกการแก้ละหมาดย้อนหลังรายเดือน)
เก็บข้อมูลการส่งยอดบันทึกแก้การขาดการละหมาดย้อนหลังเพื่อหักล้างคะแนนพฤติกรรม
| ชื่อคอลัมน์ | ประเภทข้อมูล | คีย์ | ค่าเริ่มต้น | คำอธิบาย |
| :--- | :--- | :--- | :--- | :--- |
| **prayer_correction_id** | BigInteger | Primary Key | Auto Inc | รหัสตารางเรียงลำดับในฐานข้อมูล |
| **StudentID** | VARCHAR(10) | Foreign Key | - | อ้างอิงตาราง `students.StudentID` |
| **Year** | Integer | - | - | ปี พ.ศ. / ค.ศ. ที่ดำเนินการแก้ไข |
| **Month** | Integer | - | - | เดือนที่ทำการแก้ไขการขาดละหมาด (1 - 12) |

## 4. หมวดหมู่ปีการศึกษาและภาคเรียน (Academic Year & Semester Tables)

### 4.1 ตาราง `semesters` (ตารางข้อมูลปีการศึกษาและภาคเรียน)
เก็บข้อมูลปีการศึกษาและภาคเรียนเพื่อใช้จัดกลุ่มข้อมูลกิจกรรมทั้งหมด ระบบสร้างภาคเรียนใหม่โดยอัตโนมัติตามวันที่ปัจจุบัน
| ชื่อคอลัมน์ | ประเภทข้อมูล | คีย์ | ค่าเริ่มต้น | คำอธิบาย |
| :--- | :--- | :--- | :--- | :--- |
| **semester_id** | BigInteger | Primary Key | Auto Inc | รหัสภาคเรียนเรียงลำดับในฐานข้อมูล |
| **academic_year** | Integer | Unique/Composite | - | ปีการศึกษาในรูปแบบ พ.ศ. (เช่น 2568, 2569) |
| **term** | Integer | Unique/Composite | - | ภาคเรียน (`1` = พ.ค.–ต.ค., `2` = พ.ย.–เม.ย.) |
| **start_date** | Date | Nullable | Null | วันแรกของภาคเรียน |
| **end_date** | Date | Nullable | Null | วันสุดท้ายของภาคเรียน |
| **is_active** | Boolean | - | `false` | ภาคเรียนปัจจุบันที่เปิดใช้งานอยู่ (`true` = ภาคเรียนที่แสดงโดยค่าเริ่มต้น) |
| **created_at** | Timestamp | - | Current | วันเวลาที่สร้างรายการภาคเรียนนี้ |
| **updated_at** | Timestamp | - | Current | วันเวลาที่แก้ไขรายการภาคเรียนล่าสุด |

> [!NOTE]
