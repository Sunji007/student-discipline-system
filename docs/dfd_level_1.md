# แผนภาพกระแสข้อมูลระดับที่ 1 (Data Flow Diagram - DFD Level 1)
## โครงการระบบสารสนเทศการบริหารงานวินัยและติดตามพฤติกรรมนักเรียน โรงเรียนศิริราษฎร์สามัคคี

---

## 1. บทวิเคราะห์โครงสร้างระบบ (System Analysis)

แผนภาพกระแสข้อมูลระดับที่ 1 (DFD Level 1) นี้แสดงการจำแนกการทำงานภาพรวม (Decomposition) ของระบบสารสนเทศการบริหารงานวินัยและติดตามพฤติกรรมนักเรียน โดยแบ่งออกเป็น **8 กระบวนการหลัก (Processes)**, **5 เอนทิตีภายนอก (External Entities)** และ **12 แหล่งจัดเก็บข้อมูล (Data Stores)** ซึ่งสอดคล้องกับสถาปัตยกรรมฐานข้อมูลจริง (ER-Diagram และ Data Dictionary) ของระบบ ดังนี้:

### 1.1 เอนทิตีภายนอก (External Entities)
1. **ผู้ดูแลระบบ (Admin)**: จัดการบัญชีผู้ใช้, กำหนดสิทธิ์, จัดการข้อมูลครูและนักเรียน
2. **เจ้าหน้าที่ฝ่ายกิจการนักเรียน / ครูฝ่ายปกครอง (Discipline Staff)**: จัดการกฎระเบียบวินัย, บันทึกการตัด/เพิ่มคะแนน, พิจารณาการแจ้งเบาะแส, พิจารณาคำร้องอุทธรณ์, เช็กชื่อเข้าแถว/ละหมาด
3. **ครูที่ปรึกษา / ครูประจำชั้น (Advisor Teacher)**: เช็กชื่อการเข้าแถวหน้าเสาธง, เช็กชื่อการละหมาด, ตรวจสอบพฤติกรรมนักเรียนในห้องที่ปรึกษา, ส่งข้อความสื่อสารกับผู้ปกครอง
4. **นักเรียน (Student)**: ตรวจสอบคะแนนพฤติกรรม, ตรวจสอบประวัติการเข้าแถวและละหมาด, ส่งเบาะแสการกระทำผิด, ยื่นคำร้องขออุทธรณ์คะแนน, ยื่นคำร้องขอแก้ละหมาด
5. **ผู้ปกครอง (Parent / Guardian)**: ติดตามคะแนนพฤติกรรมและสถิติการมาแถว/ละหมาดของบุตรหลาน, รับหนังสือแจ้งเตือนพฤติกรรม, ติดต่อสื่อสารกับครูที่ปรึกษา

---

### 1.2 กระบวนการหลัก (Processes: 1.0 - 8.0)
- **Process 1.0: จัดการข้อมูลผู้ใช้และข้อมูลหลัก (User & Master Data Management)**
- **Process 2.0: เช็กชื่อและประมวลผลการเข้าแถวหน้าเสาธง (Morning Flag-line Attendance Tracking)**
- **Process 3.0: จัดการคะแนนความประพฤติและกฎระเบียบวินัย (Discipline & Behavior Score Management)**
- **Process 4.0: แจ้งและตรวจสอบเบาะแสการกระทำผิด (Informant Reporting System)**
- **Process 5.0: ยื่นและพิจารณาคำร้องอุทธรณ์ความประพฤติ (Discipline Appeal Management)**
- **Process 6.0: บันทึกและติดตามผลการละหมาด (Daily Prayer Check-in & Corrections)**
- **Process 7.0: ติดต่อสื่อสารและส่งข้อความ (Internal Messaging System)**
- **Process 8.0: ประมวลผลรายงาน สถิติ และแดชบอร์ด (Reports, Statistics & Analytics)**

---

### 1.3 แหล่งจัดเก็บข้อมูล (Data Stores: D1 - D12)
| รหัสแหล่งข้อมูล | ชื่อแหล่งจัดเก็บข้อมูล (Data Store Name) | ตารางฐานข้อมูลที่เกี่ยวข้อง | รายละเอียดข้อมูล |
| :---: | :--- | :--- | :--- |
| **D1** | ข้อมูลผู้ใช้งานระบบ | `users` | ข้อมูลบัญชีผู้ใช้, รหัสผ่าน, สิทธิ์การเข้าถึง, สถานะการใช้งาน |
| **D2** | ข้อมูลนักเรียน | `students` | รหัสนักเรียน, ชื่อ-สกุล, ระดับชั้น, ห้องเรียน, คะแนนพฤติกรรมสะสม |
| **D3** | ข้อมูลครูและห้องที่ปรึกษา | `teachers`, `teacher_advisory_rooms` | รหัสครู, ชื่อ-สกุล, ตำแหน่ง, แผนก, ห้องเรียนที่ปรึกษา |
| **D4** | ข้อมูลผู้ปกครอง | `parents` | รหัสผู้ปกครอง, ความสัมพันธ์, เบอร์โทรศัพท์, ที่อยู่ |
| **D5** | ประวัติการเข้าแถวหน้าเสาธง | `attendances` | วันที่บันทึก, สถานะเข้าแถว (มา, สาย, ขาด, ลา), หมายเหตุ |
| **D6** | เกณฑ์กฎระเบียบวินัย | `behavior_rules` | รหัสกฎ, ชื่อพฤติกรรม, หมวดหมู่, ประเภท (ตัด/เพิ่ม), คะแนน |
| **D7** | ประวัติการตัด/เพิ่มคะแนน | `behavior_records` | วันที่เกิดเหตุ, กฎที่ละเมิด, คะแนนที่ปรับ, รูปถ่ายหลักฐาน, สถานะ |
| **D8** | ข้อมูลรายงานเบาะแส | `informant_reports` | วันที่แจ้ง, รายละเอียดเหตุการณ์, รูปหลักฐาน, สถานะการตรวจสอบ |
| **D9** | ข้อมูลคำร้องอุทธรณ์ | `appeals` | วันที่ยื่น, เหตุผลอุทธรณ์, หลักฐาน, ผลการพิจารณา, คะแนนที่คืน |
| **D10** | ประวัติการละหมาดและแก้ละหมาด | `prayer_records`, `prayer_corrections` | วันที่ละหมาด, คาบ (ซุฮรี/อัสรี), สถานะเช็กชื่อ, ประวัติการแก้ละหมาด |
| **D11** | กล่องข้อความสื่อสาร | `messages` | ผู้ส่ง, ผู้รับ, หัวข้อข้อความ, เนื้อหา, วันที่ส่ง, สถานะการอ่าน |
| **D12** | ปีการศึกษาและภาคเรียน | `semesters` | ปีการศึกษา (พ.ศ.), ภาคเรียน (1/2), สถานะภาคเรียนปัจจุบัน |

## 3. ตารางแจกแจงกระแสข้อมูล (Data Flow Dictionary)

ตารางด้านล่างแสดงการไหลของข้อมูลระหว่าง **External Entity**, **Process** และ **Data Store** อย่างละเอียด สำหรับนำไปประกอบรายงานทางวิชาการ:

### 3.1 กระบวนการที่ 1.0: จัดการข้อมูลผู้ใช้และข้อมูลหลัก (User & Master Data Management)
| กระแสข้อมูล (Data Flow) | ต้นทาง (Source) | ปลายทาง (Destination) | รายละเอียดข้อมูล (Description) |
| :--- | :--- | :--- | :--- |
| ข้อมูลผู้ใช้และบทบาท | Admin | Process 1.0 | รหัสประจำตัว, ชื่อ-สกุล, เลขบัตรประชาชน, รหัสผ่าน, บทบาท, สิทธิ์ |
| ข้อมูลนักเรียนและห้องเรียน | Admin | Process 1.0 | รหัสนักเรียน, ชื่อ-สกุล, ระดับชั้น, ห้องเรียน, เพศ, รูปถ่าย |
| อัปเดตข้อมูลผู้ใช้งาน | Process 1.0 | D1 (users) | บันทึก/แก้ไขข้อมูลบัญชีผู้ใช้งานระบบ |
| อัปเดตข้อมูลนักเรียน | Process 1.0 | D2 (students) | บันทึก/แก้ไข/เลื่อนชั้นปีการศึกษาอัตโนมัติ ($\ge 50$ คะแนน) |
| อัปเดตข้อมูลครูและห้องที่ปรึกษา | Process 1.0 | D3 (teachers) | บันทึกข้อมูลครู, แผนก, และห้องที่ได้รับมอบหมายเป็นที่ปรึกษา |
| อัปเดตข้อมูลผู้ปกครอง | Process 1.0 | D4 (parents) | บันทึกข้อมูลผู้ปกครองและความสัมพันธ์กับนักเรียน |
