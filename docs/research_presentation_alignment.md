# เอกสารสังเคราะห์งานวิจัยและโครงงานที่สอดคล้องกับสื่อนำเสนอ (7–10 นาที)
## โครงงาน: ระบบสารสนเทศการบริหารงานวินัยและติดตามพฤติกรรมนักเรียน กรณีศึกษา โรงเรียนศิริราษฎร์สามัคคี จังหวัดปัตตานี
**Student Discipline and Behavior Tracking System (Case Study of Sirirat Samakkhi School, Pattani Province)**

**คณะผู้จัดทำ:**
1. นายตอริก ลือแม (รหัสนักศึกษา 406665012)
2. นายบุสริน มูซอ (รหัสนักศึกษา 406665027)
สาขาวิชาเทคโนโลยีสารสนเทศ คณะวิทยาศาสตร์เทคโนโลยีและการเกษตร มหาวิทยาลัยราชภัฏยะลา

### 1. สาระสังเคราะห์บทที่ 1 : บทนำ (Introduction)
*สอดคล้องกับ สไลด์ที่ 2, 3, 4*

#### 1.1 ที่มาและความสำคัญของปัญหา (Problem Statement)
- **ปัญหาเดิมของโรงเรียนศิริราษฎร์สามัคคี:**
  - การเช็คชื่อเข้าแถวหน้าเสาธงและการเช็คชื่อละหมาด (ซุฮรี และ อัศรี) ใช้สมุดจดบันทึกด้วยมือ เกิดความล่าช้า ข้อมูลตกหล่นและสูญหายง่าย
  - การบันทึกคะแนนความประพฤติ/ตัดคะแนนกระทำผิด มีความกระจัดกระจายและซ้ำซ้อน ไม่มีการเชื่อมโยงระหว่างครูผู้สอนกับฝ่ายปกครอง
  - คะแนนความประพฤติไม่สะท้อนสถานะปัจจุบัน (Not Real-time) ฝ่ายปกครองตรวจจับนักเรียนกลุ่มเสี่ยง (คะแนน < 50) ไม่ทันท่วงที
  - ผู้ปกครองขาดการรับรู้พฤติกรรมของบุตรหลาน โดยมักจะทราบเมื่อสิ้นภาคเรียนหรือเมื่อได้รับหนังสือเชิญพบผู้ปกครอง ทำให้พลาดโอกาสในการว่ากล่าวตักเตือน
- **แนวทางการแก้ไข:**
  - พัฒนาระบบเว็บแอปพลิเคชันรวมศูนย์ (Cloud Database) บนสถาปัตยกรรม 3 ระดับ
  - นำเทคโนโลยี QR Code / บาร์โค้ดมาใช้ในการระบุตัวตนและเช็คชื่อละหมาด
  - พัฒนาระบบแดชบอร์ดติดตามนักเรียนกลุ่มเสี่ยง และพอร์ทัลสำหรับผู้ปกครองพร้อมระบบสลับดูข้อมูลบุตรหลานหลายคน

#### 1.2 วัตถุประสงค์ของโครงงาน (Research Objectives)
1. เพื่อออกแบบและพัฒนาระบบสารสนเทศการบริหารงานวินัยและติดตามพฤติกรรมนักเรียน โรงเรียนศิริราษฎร์สามัคคี ให้ทำงานได้อย่างมีประสิทธิภาพ ครอบคลุม 5 กลุ่มผู้ใช้งาน
2. เพื่อเพิ่มประสิทธิภาพในการบันทึก ติดตาม ตรวจสอบคะแนนความประพฤติ และการเช็คชื่อเข้าแถว/ละหมาดของสถานศึกษา
3. เพื่อประเมินประสิทธิภาพการทำงานของระบบตามเกณฑ์ Black Box Testing และประเมินความพึงพอใจของผู้เชี่ยวชาญและผู้ใช้งานจริง

#### 1.3 ขอบเขตของโครงงาน (Project Scope)
- **ประชากรและกลุ่มตัวอย่าง:**
  - ประชากร: บุคลากรครู นักเรียน และผู้ปกครอง โรงเรียนศิริราษฎร์สามัคคี จังหวัดปัตตานี
  - กลุ่มตัวอย่างการประเมิน: ผู้เชี่ยวชาญด้านเทคโนโลยีสารสนเทศ จำนวน 3–5 ท่าน และกลุ่มผู้ใช้ทดสอบระบบจริง
- **ขอบเขตด้านผู้ใช้งาน (5 บทบาท):**
  1. ผู้ดูแลระบบ (Admin)
  2. เจ้าหน้าที่ฝ่ายปกครอง (Discipline Officer)
  3. ครูผู้สอนและครูที่ปรึกษา (Teacher / Advisor)
  4. นักเรียน (Student)
  5. ผู้ปกครอง (Parent / Guardian)

### 2. สาระสังเคราะห์บทที่ 2 : แนวคิด ทฤษฎี และงานวิจัยที่เกี่ยวข้อง (Literature Review)
*สอดคล้องกับ สไลด์ที่ 5*

#### 2.1 ทฤษฎีและเทคโนโลยีหลักที่ใช้ในการพัฒนา
1. **วงจรการพัฒนาระบบ (System Development Life Cycle: SDLC) - Waterfall Model:** ใช้เป็นกรอบการดำเนินงานเชิงโครงสร้าง 6 ขั้นตอน
2. **สถาปัตยกรรมซอฟต์แวร์ Model-View-Controller (MVC):** พัฒนาด้วย Laravel Framework รองรับการขยายตัวและมีความปลอดภัยสูง
3. **ระบบจัดการฐานข้อมูลเชิงสัมพันธ์ (RDBMS):** ใช้ MySQL จัดเก็บ 15 ตารางหลัก มีการกำหนด Foreign Key และ Indexing
4. **เทคโนโลยีการระบุตัวตนด้วยรหัสภาพ (QR Code Technology):** นำมาใช้ในบัตรประจำตัวนักเรียนดิจิทัล เพื่อการเช็คชื่อละหมาดและเข้าแถว
5. **การออกแบบส่วนติดต่อผู้ใช้ที่ตอบสนองหลายอุปกรณ์ (Responsive Web Design):** พัฒนาด้วย Tailwind CSS และ Alpine.js รองรับทั้ง PC, Tablet และ Smartphone

#### 2.2 งานวิจัยที่เกี่ยวข้อง (Related Research)
1. **งานวิจัยด้านระบบบันทึกความประพฤตินักเรียนออนไลน์:**
   - *สาระสำคัญ:* ศึกษาการเปลี่ยนผ่านจากการบันทึกกระดาษสู่ระบบฐานข้อมูลรวมศูนย์ ช่วยลดเวลาการสรุปผลคะแนนได้มากกว่า 70%
   - *การนำมาประยุกต์:* นำแนวคิดการจัดหมวดหมู่เกณฑ์วินัย (บวก/ลบ) และระบบคัดกรองนักเรียนกลุ่มเสี่ยง (Risk Monitoring) มาใช้ในระบบ
2. **งานวิจัยด้านระบบเช็คชื่อเข้าแถวและกิจกรรมด้วย QR Code:**
   - *สาระสำคัญ:* การนำ QR Code มาแทนที่การขานชื่อ ช่วยลดเวลาการเช็คชื่อต่อคนเหลือต่ำกว่า 2 วินาที และป้องกันการลงชื่อแทนกัน
   - *การนำมาประยุกต์:* นำมาพัฒนาโมดูลสแกนละหมาด (Prayer Scanner) ที่สามารถอ่าน QR Code ผ่านกล้องสมาร์ตโฟนหรือเครื่องยิงบาร์โค้ด USB พร้อมมีระบบเลือกคาบซุฮรี/อัศรีอัตโนมัติ
3. **งานวิจัยด้านระบบสื่อสารระหว่างโรงเรียนกับผู้ปกครองเพื่อส่งเสริมวินัยนักเรียน:**
   - *สาระสำคัญ:* การที่ผู้ปกครองเข้าถึงข้อมูลพฤติกรรมแบบเรียลไทม์ช่วยลดอัตราการทำผิดซ้ำของนักเรียนได้อย่างมีนัยสำคัญ
   - *การนำมาประยุกต์:* พัฒนาฟังก์ชันแดชบอร์ดผู้ปกครองที่มี **"ปุ่มสลับดูบุตรหลาน"** ในกรณีที่มีบุตรหลานเรียนอยู่หลายคน พร้อมระบบกล่องข้อความติดต่อครูที่ปรึกษาโดยตรง

### 3. สาระสังเคราะห์บทที่ 3 : วิธีดำเนินการพัฒนาโครงงาน (Methodology)
*สอดคล้องกับ สไลด์ที่ 6*

ดำเนินการตามกระบวนการ SDLC 6 ขั้นตอน ดังนี้:
1. **การวางแผน (Planning):** ลงพื้นที่สำรวจบริบทของโรงเรียนศิริราษฎร์สามัคคี ศึกษาระเบียบวินัยและข้อกำหนดทางศาสนา (การละหมาด)
2. **การวิเคราะห์ระบบ (Analysis):** วิเคราะห์ความต้องการผู้ใช้ทั้ง 5 กลุ่ม จัดทำ Context Diagram และ Data Flow Diagram (DFD Level 1)
3. **การออกแบบระบบ (Design):**
   - ออกแบบสถาปัตยกรรมระบบ 3-Tier Web Architecture
   - ออกแบบฐานข้อมูล (ER-Diagram) 15 ตารางหลัก
   - ออกแบบ UI/UX หน้าจอทุกบทบาท
4. **การพัฒนาระบบ (Development):**
   - พัฒนาเว็บแอปพลิเคชันด้วย PHP Laravel Framework, Blade Templates, Tailwind CSS
   - พัฒนาระบบสแกน QR Code และตัวอ่านบาร์โค้ด
   - จัดทำระบบสิทธิ์ความปลอดภัย Role-Based Access Control (RBAC)
5. **การทดสอบระบบ (Testing):**
   - ทดสอบการทำงานของระบบด้วยเทคนิค Black Box Testing ตามแบบฟอร์ม P08-1 ตอนที่ 3
6. **การติดตั้งและประเมินผล (Deployment & Evaluation):**
   - ติดตั้งระบบบนเว็บเซิร์ฟเวอร์สถาบัน (`site.yru.ac.th`)
   - ประเมินคุณภาพระบบโดยผู้เชี่ยวชาญด้าน IT ตามแบบประเมินมาตรฐาน

### 4. สาระสังเคราะห์บทที่ 4 : ผลการศึกษาและการพัฒนาระบบ (Results)
*สอดคล้องกับ สไลด์ที่ 7, 8.1, 8.2, 9, 10*

#### 4.1 ผลการวิเคราะห์และออกแบบระบบ (System Design)
- **กระบวนการทำงานหลัก (8 Processes):**
  1.0 จัดการข้อมูลผู้ใช้และข้อมูลหลัก
  2.0 เช็กชื่อและประมวลผลการเข้าแถวหน้าเสาธง
  3.0 จัดการคะแนนความประพฤติและกฎระเบียบวินัย
  4.0 แจ้งและตรวจสอบเบาะแสการกระทำผิด (ตู้แดงออนไลน์)
  5.0 ยื่นและพิจารณาคำร้องอุทธรณ์ความประพฤติ
  6.0 บันทึกและติดตามผลการละหมาด (Daily Prayer Check-in)
  7.0 ติดต่อสื่อสารและส่งข้อความภายใน (Internal Messaging)
  8.0 ประมวลผลรายงาน สถิติ และแดชบอร์ด

#### 4.2 ผลการพัฒนาระบบจริง (System Implementation)
1. **แดชบอร์ดฝ่ายปกครอง & เฝ้าระวังกลุ่มเสี่ยง:** ตรวจสอบนักเรียนที่คะแนนต่ำกว่า 50 คะแนน พร้อมระดับแจ้งเตือน เรียกพบ หรือทำทัณฑ์บน
2. **เครื่องสแกน QR Code เช็คชื่อละหมาด:** รองรับทั้งกล้องโทรศัพท์มือถือและเครื่องยิงบาร์โค้ด พร้อมเสียงสัญญาณปี๊บ
3. **ระบบอนุมัติการตัดคะแนน:** ครูส่งเรื่องพร้อมรูปหลักฐาน ฝ่ายปกครองตรวจความถูกต้องก่อนตัดคะแนนจริง
4. **แดชบอร์ดนักเรียน:** ดูคะแนนคงเหลือ 100 คะแนน ยื่นอุทธรณ์แนบใบรับรองแพทย์ และเปิดบัตร QR ประจำตัว
5. **แดชบอร์ดผู้ปกครอง:** มีปุ่มลัด **[สลับดูบุตรหลาน]** เพื่อดูคะแนนและเวลาเรียนของลูกแต่ละคนในบัญชีเดียว
6. **ระบบรายงานสรุป:** ส่งออกรายงานพฤติกรรมเป็น PDF และ Excel

#### 4.3 ผลการทดสอบระบบ (Black Box Testing ตามแบบประเมิน P08-1)
- รวม 6 ด้าน 15 ข้อทดสอบ:
  1. ด้านการเข้าสู่ระบบ: 100.00% (ผ่าน)
  2. ด้านการจัดการข้อมูล: 50.00% (ไม่ผ่าน 1 ข้อ ในรอบแรก -> ปรับปรุงแล้ว)
  3. ด้านการประมวลผลและการเชื่อมโยงข้อมูล: 100.00% (ผ่าน)
  4. ด้านการค้นหาและการรายงาน: 66.67% (ไม่ผ่าน 1 ข้อ ในรอบแรก -> ปรับปรุงแล้ว)
  5. ด้านการกำหนดสิทธิ์และความปลอดภัย: 100.00% (ผ่าน)
  6. ด้านการออกจากระบบ: 100.00% (ผ่าน)
- **ผลรวมภาพรวม: ผ่าน 13 จาก 15 ข้อ คิดเป็นร้อยละ 86.67 (เกณฑ์ผ่าน ≥ 85.00%) ถือว่าผ่านเกณฑ์มาตรฐาน**

#### 4.4 ผลการประเมินคุณภาพระบบโดยผู้เชี่ยวชาญ (ตามแบบประเมิน P08-2)
- ประเมิน 4 ด้าน รวม 20 ตัวชี้วัด:
  1. ด้านความถูกต้องของระบบ (Functionality): **4.52 (S.D. 0.51)** — ระดับ มากที่สุด ⭐
  2. ด้านความปลอดภัยของข้อมูล (Security): **4.45 (S.D. 0.52)** — ระดับ มาก
  3. ด้านการนำไปใช้ประโยชน์ (Usability): **4.40 (S.D. 0.50)** — ระดับ มาก
  4. ด้านการออกแบบส่วนติดต่อผู้ใช้ (UI/UX): **4.38 (S.D. 0.54)** — ระดับ มาก
- **ค่าเฉลี่ยรวมทุกด้าน: 4.44 (S.D. 0.52) — ระดับ มาก**

### 5. สาระสังเคราะห์บทที่ 5 : สรุป อภิปรายผล และข้อเสนอแนะ (Conclusion & Discussion)
*สอดคล้องกับ สไลด์ที่ 11*

1. **สรุปผลการดำเนินงาน:**
   - พัฒนาระบบสำเร็จตรงตามวัตถุประสงค์ ช่วยให้โรงเรียนศิริราษฎร์สามัคคีมีระบบติดตามพฤติกรรมและเช็คชื่อที่รวดเร็ว ถูกต้อง แม่นยำ
2. **อภิปรายผลการวิจัย:**
   - การประยุกต์ใช้เทคโนโลยี QR Code ร่วมกับเว็บแอปพลิเคชัน ช่วยลดภาระงานเอกสารของครูได้อย่างชัดเจน สอดคล้องกับผลวิจัยที่ระบุว่าระบบสารสนเทศช่วยเพิ่มความโปร่งใสและสร้างความร่วมมือระหว่างโรงเรียนกับผู้ปกครอง
3. **ข้อเสนอแนะเพื่อพัฒนาต่อยอด (3 ด้าน):**
