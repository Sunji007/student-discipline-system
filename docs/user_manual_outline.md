# บทนำและข้อมูลเบื้องต้นของระบบ

ระบบสารสนเทศการบริหารงานวินัยและติดตามพฤติกรรมนักเรียน แบ่งการทำงานตามสิทธิ์การเข้าใช้งาน (Role-based Access Control) ออกเป็น 5 กลุ่มผู้ใช้งานหลัก ได้แก่:
1. **ผู้ดูแลระบบ (Admin)** : มีหน้าที่จัดการโครงสร้างข้อมูลผู้ใช้ นักเรียน ครู และสิทธิ์ระบบ
2. **ฝ่ายปกครอง (Discipline Officer)** : มีหน้าที่ตั้งเกณฑ์กฎระเบียบ อนุมัติตัด/เพิ่มคะแนน และพิจารณาคำร้องอุทธรณ์
3. **ครูผู้สอน / ครูที่ปรึกษา (Teacher)** : มีหน้าที่เช็คชื่อประจำวัน บันทึกพฤติกรรมนักเรียน และสแกนละหมาด
4. **นักเรียน (Student)** : มีหน้าที่ตรวจสอบคะแนนตนเอง ยื่นอุทธรณ์ แสดง QR Code ละหมาด และแจ้งเบาะแส
5. **ผู้ปกครอง (Parent)** : มีหน้าที่ติดตามคะแนนพฤติกรรม เวลาเรียน และติดต่อครูที่ปรึกษา

`https://406665027.site.yru.ac.th` หรือ `http://localhost/student-discipline-system/public`

**บัญชีผู้ใช้งานจำลองสำหรับทดสอบระบบ (Default Test Accounts):**

### 1.2) การจัดการข้อมูลผู้ใช้งานระบบ (User Management)

![ภาพที่ 3](manual_images/fig_03.png)
**ภาพที่ 3** หน้าจอแสดงรายการข้อมูลผู้ใช้งาน

**คำอธิบายขั้นตอนการทำงาน:**
จากภาพที่ 3 ผู้ดูแลระบบสามารถจัดการผู้ใช้งานในระบบได้ดังนี้:
* คลิกปุ่ม **[ + เพิ่มผู้ใช้งาน ]** เพื่อสร้างบัญชีผู้ใช้งานใหม่
* ช่องค้นหาและตัวกรองบทบาท สำหรับค้นหาผู้ใช้ตามชื่อ นามสกุล หรือกลุ่มผู้ใช้
* คลิกปุ่ม **[ แก้ไข (ไอคอนดินสอ) ]** เพื่อแก้ไขข้อมูลส่วนตัว หรือรีเซ็ตรหัสผ่าน
* คลิกปุ่ม **[ ลบ (ไอคอนถังขยะ) ]** เพื่อปิดการใช้งานหรือลบบัญชีผู้ใช้ออกจากระบบ

![ภาพที่ 4](manual_images/fig_04.png)
**ภาพที่ 4** หน้าจอแบบฟอร์มเพิ่มข้อมูลผู้ใช้งาน

**คำอธิบายขั้นตอนการทำงาน:**
จากภาพที่ 4 ผู้ดูแลระบบทำการกรอกข้อมูลในแบบฟอร์ม:
1. เลือกบทบาทผู้ใช้งาน (Role)
2. ป้อนชื่อ-นามสกุล, เลขประจำตัวประชาชน, เบอร์โทรศัพท์ และอีเมล
3. กำหนดชื่อผู้ใช้ (Username) และรหัสผ่าน (Password)
4. คลิกปุ่ม **[ บันทึก ]** เพื่อยืนยันการบันทึกข้อมูล หรือคลิกปุ่ม **[ ยกเลิก ]** เพื่อปิดแบบฟอร์ม

### 4.2) การตรวจสอบประวัติและสถิติการเข้าแถว (Student Attendance)

![ภาพที่ 26](manual_images/fig_26.png)
**ภาพที่ 26** หน้าจอปฏิทินและสถิติการเข้าแถวของนักเรียน

**คำอธิบายขั้นตอนการทำงาน:**
จากภาพที่ 26 นักเรียนสามารถติดตามข้อมูลการมาเรียนและการเข้าแถวของตนเองได้อย่างละเอียด:
1. ดูสถิติสรุปภาพรวมรายเดือน ได้แก่ จำนวนครั้งที่ **เข้าแถว**, **มาสาย** และ **ขาดเข้าแถว** พร้อมเปอร์เซ็นต์ความสม่ำเสมอ
2. ตรวจสอบสถานะการเข้าแถวบน **ปฏิทินประจำเดือน** โดยระบบจะแสดงสถานะแต่ละวันอย่างชัดเจน

4. คลิกปุ่ม **[ สรุปสถิติแต่ละเดือน (ร้อยละ %) ]** เพื่อเปิดหน้าต่างดูรายงานสถิติการเข้าแถวแบบแยกตามรายเดือนตลอดทั้งภาคเรียน

จากภาพที่ 27 หากนักเรียนถูกตัดคะแนนโดยมีเหตุจำเป็น:
1. เลือกรายการบันทึกพฤติกรรมที่ต้องการอุทธรณ์
2. กรอกข้อความชี้แจงเหตุผลและข้อเท็จจริง
3. อัปโหลดรูปภาพหลักฐาน เช่น ใบรับรองแพทย์ หรือใบมอบหมายงาน
4. คลิกปุ่ม **[ ส่งคำร้องอุทธรณ์ ]** และรอผลการพิจารณาจากฝ่ายปกครอง

---

### 4.4) การเปิดบัตร QR Code ประจำตัวเพื่อเช็คชื่อละหมาด (Prayer QR Check-in)

![ภาพที่ 28](manual_images/fig_28.png)
**ภาพที่ 28** หน้าจอแสดง QR Code ประจำตัวสำหรับเช็คชื่อละหมาด

**คำอธิบายขั้นตอนการทำงาน:**
จากภาพที่ 28 นักเรียนเปิดหน้านี้ผ่านโทรศัพท์มือถือ เพื่อแสดง QR Code ประจำตัวให้ครูสแกน ณ จุดเช็คชื่อละหมาด พร้อมทั้งสามารถดูประวัติการเช็คชื่อละหมาดของวันนี้ได้ทันที

---

### 4.5) การส่งเรื่องแจ้งเบาะแสพฤติกรรม (Informant Report)

![ภาพที่ 29](manual_images/fig_29.png)
**ภาพที่ 29** หน้าจอแจ้งเบาะแสพฤติกรรมที่ไม่เหมาะสม

**คำอธิบายขั้นตอนการทำงาน:**
จากภาพที่ 29 นักเรียนสามารถร่วมดูแลความปลอดภัยในโรงเรียน:
1. กรอกรายละเอียดเหตุการณ์ วันที่ และสถานที่
2. เลือกว่าจะ **"เปิดเผยชื่อผู้แจ้ง"** หรือ **"แจ้งแบบปกปิดชื่อ (Anonymous)"** เพื่อความปลอดภัย
3. คลิกปุ่ม **[ ส่งรายงานเบาะแส ]** เรื่องจะส่งตรงไปยังฝ่ายปกครองโดยเฉพาะ

# 5. กลุ่มของผู้ปกครอง (Parent / Guardian)

### 5.1) หน้าแดชบอร์ดผู้ปกครองและการสลับดูข้อมูลบุตรหลาน

![ภาพที่ 30](manual_images/fig_30.png)
**ภาพที่ 30** หน้าแดชบอร์ดผู้ปกครอง

**คำอธิบายขั้นตอนการทำงาน:**
จากภาพที่ 30 ผู้ปกครองดูภาพรวมความประพฤติของบุตรหลาน:
* แสดงคะแนนความประพฤติคงเหลือของบุตรหลาน
* กรณีมีบุตรหลานเรียนอยู่มากกว่า 1 คน สามารถคลิกปุ่ม **[ สลับดูบุตรหลาน ]** เพื่อเลือกดูข้อมูลของแต่ละคนได้อย่างสะดวก

---

### 5.2) การตรวจสอบคะแนนพฤติกรรมและเวลาเรียน

![ภาพที่ 31](manual_images/fig_31.png)
**ภาพที่ 31** หน้าจอประวัติพฤติกรรมและการเช็คชื่อบุตรหลาน

**คำอธิบายขั้นตอนการทำงาน:**
จากภาพที่ 31 แสดงรายละเอียดบันทึกการหักคะแนน ย้อนหลัง สาเหตุ วันที่ และประวัติการขาด-ลา-มาสาย เพื่อให้ผู้ปกครองสามารถติดตามและตักเตือนบุตรหลานได้ทันท่วงที

---

### 5.3) การส่งข้อความติดต่อครูที่ปรึกษา (Parent Messaging)

![ภาพที่ 32](manual_images/fig_32.png)
**ภาพที่ 32** หน้าจอส่งข้อความติดต่อครูที่ปรึกษา

**คำอธิบายขั้นตอนการทำงาน:**
จากภาพที่ 32 ผู้ปกครองสามารถพิมพ์ข้อความสอบถามปัญหา หรือแจ้งการลากิจ/ลาป่วย พร้อมแนบเอกสารส่งตรงไปยังครูที่ปรึกษาได้อย่างสะดวกและเป็นส่วนตัว
