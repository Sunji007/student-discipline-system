# DFD Level 0 (Diagram 0) — ระบบบริหารพฤติกรรมนักเรียน

โค้ด Mermaid สำหรับวางใน [mermaid.live](https://mermaid.live) — คัดลอกทั้งบล็อก ```mermaid ด้านล่างได้เลย

## การจัดเส้น (แก้ปัญหาเส้นทับกัน)

- **ใช้ layout engine ELK** — Mermaid v12 (ที่ mermaid.live ใช้) ใช้ ELK เป็นค่าเริ่มต้นของ flowchart อยู่แล้ว และกำกับไว้ใน frontmatter (`config: layout: elk`) ให้ชัดเจน; บรรทัด `%%{init: ...}%%` เป็น fallback สำหรับ Mermaid เวอร์ชันเก่า (v10–v11) เช่น extension ใน VS Code
- **ลูกศรอ่าน/เขียนคลังข้อมูลรวมเป็นสองหัว `<-->`** 6 คู่ (P1↔D1, P2↔D2, P2↔D3, P5↔D6, P6↔D7, P7↔D8) — ลดจาก 43 → 37 เส้น และกำจัดเส้นย้อนกลับ
- **วางแนวตั้ง (`flowchart TB`)** — ผลวัดจริงด้วย engine ตัวเดียวกับ Mermaid: ลดจุดที่เส้นตัดกันจาก 30 → 16 จุด ไม่มีเส้นทับซ้อนกันเอง และไม่มีเส้นพาดผ่านกล่องใด ๆ (เทียบทางเลือกอื่นแล้วชุดนี้ต่ำสุด)
- ทิศทางเปลี่ยนเป็นแนวนอนได้: แก้ `flowchart TB` → `flowchart LR`

```mermaid
---
title: DFD Level 0 — ระบบบริหารพฤติกรรมนักเรียน (Student Discipline System)
config:
  layout: elk
  flowchart:
    nodeSpacing: 50
    rankSpacing: 80
---
%%{init: {"flowchart": {"defaultRenderer": "elk"}}}%%
flowchart TB
    %% ================= หน่วยงานภายนอก (External Entities) =================

    P2(("2.0<br/>บันทึก/อนุมัติพฤติกรรม<br/>และคำนวณคะแนน<br/>(Behavior)"))
    P3(("3.0<br/>เช็คชื่อเข้าแถว<br/>(Attendance)"))
    P4(("4.0<br/>บันทึกการละหมาด<br/>(Prayer QR)"))
    P5(("5.0<br/>พิจารณาอุทธรณ์<br/>(Appeal)"))
    P6(("6.0<br/>รับ/สอบสวนข้อมูลแจ้ง<br/>(Informant)"))
    P7(("7.0<br/>ส่งข้อความ<br/>และแจ้งเตือน<br/>(Message)"))
    P8(("8.0<br/>รายงานสรุป<br/>และแดชบอร์ด<br/>(Report)"))

    %% ================= คลังข้อมูล (Data Stores) =================
    D1[("D1 บัญชีผู้ใช้และสิทธิ์<br/>(Users & Permissions)")]
    D2[("D2 ข้อมูลนักเรียนและ<br/>คะแนนพฤติกรรม<br/>(Students & Scores)")]
    D3[("D3 บันทึกพฤติกรรมและ<br/>เกณฑ์การตัด/เพิ่มคะแนน<br/>(Records & Rules)")]
    D4[("D4 การเช็คชื่อเข้าแถว<br/>(Attendance)")]
    D5[("D5 บันทึกการละหมาด<br/>(Prayer Records)")]
    D6[("D6 คำร้องอุทธรณ์<br/>(Appeals)")]
    D7[("D7 ข้อมูลแจ้งเบาะแส<br/>(Informant Reports)")]
    D8[("D8 ข้อความ<br/>(Messages)")]

    %% ===== ผู้ดูแลระบบ =====
    ADMIN -->|"เพิ่ม/แก้ไขบัญชี สิทธิ์ ภาคเรียน"| P1
    P1 <-->|"บัญชีผู้ใช้/สิทธิ์"| D1

    %% ===== พฤติกรรมและคะแนน (2.0) =====
    DISC -->|"บันทึก/อนุมัติพฤติกรรม กำหนดเกณฑ์"| P2
    TEACH -->|"รายงานพฤติกรรมนักเรียน"| P2
    P2 <-->|"คะแนน/สถานะเสี่ยง"| D2
    P2 <-->|"พฤติกรรม/เกณฑ์"| D3
    P2 -->|"คะแนน/สถานะความเสี่ยง"| STU

    %% ===== เช็คชื่อเข้าแถว (3.0) =====
    TEACH -->|"บันทึกเข้าแถว (มา/สาย/ขาด)"| P3
    P3 -->|"บันทึกการเข้าแถว"| D4
    P3 -->|"ข้อมูลขาด/สายเกินเกณฑ์"| P2

    %% ===== ละหมาด QR (4.0) =====
    STU -->|"แสดง QR ละหมาด"| P4
    DISC -->|"สแกน QR/บันทึกสถานะ"| P4
    P4 -->|"บันทึกการละหมาด"| D5

    %% ===== อุทธรณ์ (5.0) =====
    STU -->|"ยื่นอุทธรณ์+หลักฐาน"| P5
    P5 <-->|"คำร้องอุทธรณ์/สถานะ"| D6
    DISC -->|"ผลการพิจารณา (คืนคะแนน)"| P5
    P5 -->|"สถานะ/ผลอุทธรณ์"| STU
    P5 -->|"ข้อมูลคืนคะแนน"| P2

    %% ===== ข้อมูลแจ้งเบาะแส (6.0) =====
    STU -->|"แจ้งเบาะแส (ไม่เกิน 3 ครั้ง/วัน)"| P6
    P6 <-->|"เรื่องแจ้ง/ผลสอบสวน"| D7
    DISC -->|"ผลการสอบสวน"| P6
    P6 -->|"สถานะเรื่องแจ้ง"| STU
    P6 -->|"ตัดคะแนนผู้แจ้งเท็จ"| P2
    P6 -->|"แจ้งผู้ถูกกล่าวหา"| P7

    %% ===== ข้อความ/แจ้งเตือน (7.0) =====
    STU -->|"ส่งข้อความ"| P7
    TEACH -->|"ส่งข้อความ"| P7
    DISC -->|"ส่งข้อความ (CC ผู้ปกครอง)"| P7
    P7 <-->|"ข้อความ"| D8
    P7 -->|"กล่องข้อความ/แจ้งเตือน"| STU
    P7 -->|"ข้อความ/แจ้งเตือน"| PAR

    %% ===== รายงานสรุป (8.0) =====
    PAR -->|"เรียกดูข้อมูลบุตร"| P8
    D2 -->|"ข้อมูลคะแนน/ความเสี่ยง"| P8
    D3 -->|"ข้อมูลพฤติกรรม"| P8
    D4 -->|"ข้อมูลการเข้าแถว"| P8
    D5 -->|"ข้อมูลการละหมาด"| P8
    P8 -->|"รายงานสรุป/นักเรียนเสี่ยง"| DISC
```

## ข้อจำกัด

Mermaid จัดเส้นอัตโนมัติทั้งหมด ไม่สามารถลากเส้นเองได้ จึงไม่สามารถการันตี 0 จุดตัดได้ — 16 จุดที่เหลือเป็นผลจากความหนาแน่นของกราฟ (โดยเฉพาะเส้นจากคลังข้อมูล D2–D5 เข้ากระบวนการ 8.0) ซึ่งน้อยที่สุดแล้วเทียบกับทุกทางเลือกที่วัดได้ ถ้าต้องการผังสำหรับพิมพ์ที่เส้นตัดกันน้อยกว่านี้ ทางเลือกคือแยกเป็น 2 ผังย่อย (ผังวินัย/คะแนน: 2.0, 5.0, 6.0 และผังปฏิบัติการ: 1.0, 3.0, 4.0, 7.0, 8.0)
